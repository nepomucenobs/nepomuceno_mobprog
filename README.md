# Laboratory Discussion

I made the post card able to show a picture, but only when a post actually has one. Each post is given an optional picture, and if a post doesn't have one, that spot will be left empty. When the app builds a card, it first checks whether a picture was provided. In my feed, my own post has no picture, while the other post has a picture. Also, if the picture file can't be found, a plain grey box appears instead of the app breaking. Lastly, I made sure the folder containing the pictures was registered in the project so the app knows where to find them.
